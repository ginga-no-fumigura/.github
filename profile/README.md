著作権の保護期間が満了した刊本から起こした近代の詩・短歌・俳句を、作品ごとのリポジトリに置いています。誰でも読み・使い・直せます（CC0 1.0）。

**サイトで読む：[銀河の文庫（ぎんがのふみぐら）](https://informanellica.com/ginga-no-fumigura/)**

「銀河」は天の川のことです。「ふみぐら」は書物の蔵のことです。
